# Change plan — skills.sshlg.me, 2026-08-26

Triaged on four axes and no scalar — `impact`, `irreversibility`, `uncertainty`
(evidence tier), `coordination`, in that order; the first that separates two rows
decides. `effort` is recorded and never ranks.

## Blockers — none

Crawl access, canonicalization and the sitemap are clean. Nothing is stopping an
engine from reading this site.

## Leaks — shipped in this pass

| # | Finding | Tier | Impact | Irrev. | Coord. | Effort | State |
|---|---|---|---|---|---|---|---|
| L1 | Author entity absent from 2 of 4 templates, including the page most likely to be quoted | `CONFIRMED` | med-high | low | none | S | **done** — emitted by the layout, so no template can be missing it |
| L2 | `/agents/` duplicated the front page's 9-card grid | `CONFIRMED` | med | low | none | S | **done** — chips plus one link to the descriptions |

## Gains — one shipped, one open

| # | Finding | Tier | Impact | Irrev. | Coord. | Effort | State |
|---|---|---|---|---|---|---|---|
| G1 | The answers on `/agents/` had no questions attached | `STUDY` | med | low | none | M | **done** — 5 visible Q&A pairs, `FAQPage` built from the same array the page renders |
| G2 | `/` sits at 47.9% content in the first read window | `FIELD` | med | low | none | M | **open** — see below |

**G2 is deliberately not fixed in this pass.** The driver on `/` is the 9-card
grid, and unlike `/agents/` that grid **is** the page's job — it is the family, and
removing or deferring it would trade an engine's first read against the reader's.
The honest options are to move the grid below the install section, or to accept the
share. That is a content decision with a real trade-off, not a defect, so it is
written down rather than taken unilaterally.

## Experiments — none

Nothing in this pass rests on a `HYPOTHESIS`, so there is nothing to run as an
experiment. No `experiments.md` was created; an empty one would read as coverage.

## What the plan cannot claim

Without Search Console there is no declared-vs-indexed figure, so **none of the
above is known to have changed what an engine does** — only what the page offers
it. The next audit that runs with a credential should open by measuring that,
because it is the one question this pass could not ask.

## Recommended next action, exactly one

Decide G2: move the card grid below `## Install` on `/` and re-measure the read
budget, or record the 47.9% as accepted. Nothing else in this plan is open.

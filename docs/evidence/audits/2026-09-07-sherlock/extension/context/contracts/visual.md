# Контракт visual

Статус: целевая спецификация, не утверждение о существующем runtime.

VisualDirection: locked brand/accessibility invariants, open axes, reference traits, real key-state content, target platform, rendered candidates, selected rationale. Для нового направления 2–3 ограниченных рендера; exact Figma implementation и выбранное пользователем направление не требуют ритуальной развилки. Меняются composition/type/spacing/imagery/control anatomy, а не только accent. После выбора semantic tokens и reusable pack contract. RenderCritique: same viewport/content, specific defect, intended change, rerender evidence, remaining limitations. Mechanical constraints и craft rubric независимы; accessibility semantics не жертвуются ради kit API. Browser-only preview не доказывает native behavior.

Источники требований и доказательства: [brief](../../work-brief.md), [реестр замечаний](../../findings-final.json).

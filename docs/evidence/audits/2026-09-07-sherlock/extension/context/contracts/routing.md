# Контракт routing

Статус: целевая спецификация, не утверждение о существующем runtime.

RouteRequest {intent, subject, effects, facets, explicit_skills, exclusions, host}. Пример read-only family audit → make-skill + evidence-docs, без release. Changes to skills → task-pipeline delivery + make-skill construction; product behavior → super-ux; visuals → sheleg-design; copy читает brand/scenarios. agent-stack применяется когда строится agent system; agent-sync когда координируются ресурсы исполнителей. Explicit user/system constraints сильнее local routing. Refusal scope принадлежит конкретному маршруту; цитаты/negations не являются согласиями или глобальным выключателем. Output RouteDecision перечисляет выбранное, причины, host capability и реально прочитанные paths. Candidate search не считается доказанным выбором.

Источники требований и доказательства: [brief](../../work-brief.md), [реестр замечаний](../../findings-final.json).

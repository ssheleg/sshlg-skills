## Measurements

Scripted simulation (`SSHLG_SKILLS_NO_PROBE=1`, sandbox HOME, two enabled plugins that hook SessionStart): 5 sessions x 12 prompts, one `compact` per session mid-way, real hook processes.

| | Routing notes printed | Routing chars | Injector lines | Injector chars | SessionStart context chars |
|---|---|---|---|---|---|
| HEAD | 40 | 18,735 | 10 | 1,830 | 6,270 |
| branch | 25 | 9,205 | 1 | 183 | 4,605 |

Note count 25 = 5 sessions x (first-sight routes + the routes again after the `compact`). The production baseline (1,302 notes / 547,690 chars in 14 days) is a different mix; the simulation measures the mechanism, not the production total.

Hook latency, wall time per process, 10 runs, median ms, sandbox HOME, minimal realistic payloads (this machine, macOS, node startup alone about 55-75 ms; run-to-run noise about 20 ms, so three full sweeps are shown for the changed hook):

| Hook | Before | After |
|---|---|---|
| `node -e 0` (floor) | 75 | 53-63 |
| `session-start` | 75 | 79-82 |
| `user-prompt-submit` (routed prompt) | 182 | 72-84 (and 198 in one noisy sweep, min 63-96) |
| `user-prompt-submit` (no route) | 164 | 66-69 |
| `pre-tool-use` Read / Edit / Bash | 63 / 64 / 60 | 53-177 / 56-86 / 62-78 |
| `post-tool-use` Bash (no skills-CLI) | 64 | 55-81 |
| `repo-gate` | 70 | 52-85 |
| `notification`, `config-change`, `file-changed`, `statusline` | 64, 59, 58, 65 | 67-69, 59-97, 60-109, 65-113 |
| `ps -Ao args=` alone | 104 | 135-199 (machine-load dependent) |

Findings: only `user-prompt-submit` exceeded 150 ms on a common path (it runs on every prompt). Cause: 60 ms of the hook was `match()` building and running about 370 regular expressions; after the prefilter `match()` costs about 5 ms cold. Every other hook sits at node startup plus 0-25 ms. `post-tool-use`'s `execSync('ps -Ao args=')` costs 100-200 ms but runs only after a skills-CLI command (`hygiene.skillsCli(command)`), which is not a common path; not optimised (rule: only common paths over 150 ms).

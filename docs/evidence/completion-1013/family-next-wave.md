## Order and common execution contract

1. **FW00 reconciliation** precedes new member edits. Re-read the exact owner head, current backlog, HANDOFF, working rules and active leases. Resolve duplicates, split implementation from runtime proof, and retain a reason for each deferred row. Board prose alone never authorizes claiming the defect still reproduces.
2. **Wave A:** FW01 temp-accounting, FW02 parser/guard defects, FW03 credential-boundary fixtures, and FW04 lease lifecycle can proceed in separate owner worktrees after coordination. Do not run overlapping full suites. A same-owner queue is serial even when different packets mention it.
3. **Wave B:** FW05 source-derived design/UX facts and FW06 collector contracts after their owning guards are trustworthy. FW07 context reduction starts with measurements and a contract, not deletion.
4. **Wave C:** FW08 behavioral discovery/evaluation and FW09 broader contracts only after local artifacts and external prerequisites are explicit. Missing provider/browser/account evidence remains NOT_RUN; a passed fixture is not live acceptance.

Every development packet uses task-pipeline in the owning repository, agent-sync for guarded files, make-skill when the skill's structure/discovery/package changes, and evidence-docs for claims. Reproduce the named defect before changing it. Save a bounded negative and a meaningful nearby counterexample; run owner-required focused checks, then the parent schedules aggregate gates. A verifier who did not write the change checks docs, business behavior, implementation and cross-owner seams against the original operator objective. Fixes enter the next wave with evidence; no blanket “all bugs gone” verdict.

Deliver each packet as a pushed owner branch with exact SHA, one HANDOFF entry, tests actually run, residual bounds, prerequisites and exact next task. Review/merge/release and installed/native readback are distinct states. Cross-project asks, when needed, go through the Fabric project board and cite the message ID; this plan does not substitute chat for that record.

## Scoring before seeing the arm or cost

Two independent source-competent reviewers first score shuffled opaque artifacts against the frozen case fixture and every required/forbidden dimension. Withhold arm/index/source/cost/raw-trace mappings. A deterministic masking pass replaces only plugin path/version identifiers with neutral instruction-source placeholders, retaining project evidence paths and all substantive text; preserve the original artifact and transformation map/hashes. This withholds explicit labels, but intrinsic content may reveal an arm, so do not call it a formally blind experiment. Reviewers record short quotations and project file:line evidence before unmasking; disagreement remains UNKNOWN until source-grounded adjudication, never an averaged pass.

Trace review is separate: confirm actual successful Skill load, stage-specific read provenance and semantic happens-before relations. Independent file reads need no exact total order. A correct final answer without required source retrieval can pass artifact quality while failing navigation; a source read without a good decision can pass retrieval while failing quality. A stated plan to test is not a completed test. Missing/invalid artifact, invented approval, false execution, premature gate advancement or foreign-resource action fails the corresponding dimension. No live environment change is requested or scored as executed.

Report all paired wins/losses/ties by case, every dimension, invalid/NOT_RUN cells, total input including cached components, repeated-read costs, output, per-request maxima, elapsed time and reported list usage. Use the seven nonfault pairs for median total-input delta, with all per-case totals shown. k=1 is a screen, not reliability or noninferiority; tasks sharing a stage/harness are correlated. Even8/8 cannot prove zero quality loss. A positive screen requires no candidate-only gate failure or forbidden claim, required read provenance, and at least10% median total-input reduction. It authorizes only proposing a larger new validation, **not compression adoption or a global quality claim**.

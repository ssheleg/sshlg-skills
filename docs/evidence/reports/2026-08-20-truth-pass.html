What was actually broken

Every item below was reproduced before it was fixed, and every fix was watched refusing the defect it exists for. None of these was found by reading; each was found by asking one question per repository — what does this assert that nothing recomputes?

  • The commit gate could be walked past by the most ordinary command. git add -A && git commit ran no tests at all: ownership was decided by asking the index at PreToolUse, before the command runs, when nothing is staged yet.
  • The route gate had been silent for six days — it read the file exists where the ledger said stage: 10 acceptance — verdict pass.
  • An assertion could be neutered while the self-test printed “each watched failing” at exit 0 — the PII guard among them, advertised by name in a shipped reference.
  • A made-up public number passed the check that exists to catch it: the sourced corpus was one concatenated string, so any substring of it counted as sourced.
  • An audit refused a score and computed one, with a formula in which 3 × 1 / 3 and 1 × 1 / 1 both print 1.
  • A claim tag could outlive its lease with no command able to reach it — the one open issue in the family, reproduced and closed.
  • Four style packs contradicted the token layers shipped beside them, and the six new sweeps found 24 more on their first run.
  • Eleven documented facts were false with the gate green, and a class registered for exactly its own incident printed dormant while the false number shipped in three surfaces.
  • All nine newest tags were lightweight, so git submodule status reported every member at its previous version while every pin was correct.

Found by releasing, not by reading

The release itself was the sharpest instrument of the day, and what it found is the part worth keeping.

  • Four members' own guards made their version-bump commit impossible — a tag cannot exist before the commit that bumps to it. Ahead of the newest tag is a disclosure now; behind it still fails, which is the direction the defect was about.
  • A tag push could cancel its own release through a shared concurrency group, skipping the publish while the run list showed a green validate beside the tag. Measured live on one member, latent in two more.
  • Five plants across three repositories were pinned to the literal of the fact they measure, so they stopped landing on every release. Three of the five were broken by this very release and repaired inside it. A plant that does not land is a check nobody ran, reported green.
  • A member fixed its coordination config and left the snapshot describing the old shape — and no member's own gate asks that question. The umbrella's does, one layer up, and it went red on the release.
Two failures were mine and are recorded as such: one commit went in with the gate red because its exit code was read into an echo instead of a &&, and one “fix” to a guard used pathlib.Path where the module imports Path, with a bare except swallowing the error so the exemption silently never applied.

The manifesto

Its version was deliberately not raised; the corrections went into 1.0. Eight gates green, and the one that did not exist now does.

  • “For a day and a half” was a restated interval. The commits give two days and six hours. It is registered with both endpoints and re-derived from them on every run — in the one paragraph whose subject is a claim that went stale.
  • Eight of nine tools had no negative control, in the repository whose own text requires a check to be shown able to discriminate. tools/negatives.py plants one defect per gate: 13 cases, 13 refused, each asserting that the plant landed first.
  • Two footnote labels named a different line range than their own links; the asset fingerprints covered 6 of 13 urls; the sitemap told crawlers the text had not moved since the day the error shipped; llms.txt dropped the one measured row the prose refuses to delete.

What stays open, and why

Named rather than closed, because the operator's scope for this pass was truth before features.

  • 11 conformance rows — among them the requirement ids themselves: the manifesto carries none, the extracted set was never committed, and an independent re-derivation disagrees with the programme's numbering. Publishing that derivation would silently renumber every citation in the family, which is worse than an unresolvable id. A new row must now cite manifesto.md:<line>, and the 42 existing rows are grandfathered in an enumerated marker.
  • Feature wishes stay open with a computed priority — an agent-traffic log parser, a graph-backed harvest, GSC pagination, DTCG token export. They were never in this pass's scope.
  • One green run does not close a flake row. The 412-plant suite passed first try and its row stays open, because that is what the row exists to distrust.
  • 27 expired lease files across the machine are reported and untouched. Their run ids match a shared fallback identity, so the match proves nothing — state you cannot prove is yours is reported, not deleted.

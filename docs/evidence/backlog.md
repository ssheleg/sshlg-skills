# Board — sshlg-skills

Everything this repository knows it owes, in one place. A carry-over that
leaves a run still open lands here with an id; `/task-pipeline checkup` reads
this file when no run is in flight, which is exactly when accumulated debt is
invisible.

**Priority is computed, not felt.** `P = blast × (1 + age_runs) / effort`,
where *blast* is who is hurt if it stays (3 = a user of the pack, 2 = the
operator of this machine, 1 = a future run of this repo), *age_runs* is how
many **distinct days** carrying a run stamp the row has survived, and *effort*
is rough size (1 = under an hour, 2 = a session, 3 = its own run).

**Days, not stamps, and the difference is not cosmetic.** The stamp table holds
38 stamps over 9 days, thirteen of them on one afternoon — counting stamps
would let a single busy day outrank a row ignored for a week. The term exists
so a row that keeps being passed over rises; a run that stamped thirteen times
in an afternoon passed a row over once.

Recomputed at stage 10 rather than inherited, so a row cannot keep a rank it
earned when it was new — and **`test/validate.py` now recomputes it**, because
for eleven days nothing did. `B-07` and `B-08` read age 2 against seven
stamp-days, `B-29` and `B-51` read 0 against three and one; the age term was a
constant, so the board ranked newest-first while this paragraph claimed the
opposite.


**A decision is not debt, and `waived` is how the board says so.** A row that records a
deliberate *no* accrues age like any other and eventually outranks real work — B-07 and
B-08 reached the top of this board on 2026-08-16 with seven stamp-days each, and the cycle
that picked them up spent itself re-deriving two decisions that were correct when made and
still correct. Fixing the age term one cycle earlier is what exposed this: the constant had
been hiding it.

So `waived` is a state, not a flavour of open. A waived row is **not counted open**, carries
**no priority** (`—`), and must name what would bring it back:

```
| B-NNN | … | … | 1 | 7 | 3 | — | waived — revisit: <the condition, and how to measure it> |
```

**The `revisit:` clause is mandatory and the validator enforces it.** A waiver with no
trigger is not a decision, it is a row nobody will ever reconsider — and the trigger has to
be something a later run can measure, not a feeling that it is time.

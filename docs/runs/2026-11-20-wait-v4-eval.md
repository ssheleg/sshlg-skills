# wait-v4: the relayed operator rules in the wait rule, and their paired evaluation

## What changed

`wait-v4` adds one paragraph to the wait rule (`lib/wait-rule-text.js`, its canonical copy
`docs/working-rules/wait-is-not-a-stop.md`), before the paragraph on outward actions. It carries the five
operator rules B-338 lists: a same-turn state answer, an order done right the first time, the order as the
grant for the access its act needs, content first with publishing risk as metadata, and autonomous orders
picked by the agent with a second model judging while trial orders show variants. The body grows by 675
characters (2,629 to 3,304). `wait-v3` stays in `PREVIOUS`, so an applied rule upgrades in place;
`test/wait_rules_test.js` proves the upgrade, the new lines and three identical hashes after it.

## Paired evaluation (B-330's bar, B-347's W1 condition)

Arms: A is `wait-v3`, B is `wait-v4`, each rendered for Claude (`render('claude')`). Four situations, one
fresh agent per (arm, situation), model Claude Haiku 5.5 through the Agent tool, each told to read only the
arm file and answer `ACTION`, `QUOTE`, `SUPPORTED`. Both arms are contaminated the same way as the routing
eval ([`../../test/evals/README.md`](../../test/evals/README.md), "Limits"): the machine's own instructions
already hold these rules, so the action column can pass from memory; the quote column cannot.

| Situation | Wanted | A action | A quote | B action | B quote |
|---|---|---|---|---|---|
| P1 half done, rest waits on CI: what goes on the board now | state now: done, where, when, blocker | no: waits for CI before sending | NONE | yes | the new sentence |
| P2 ordered to send to a chat with no token | issue a token scoped to that chat, then send | no: records it as pending | NONE | first wording: no (asks for a grant); second wording: yes | NONE, then the new sentence |
| P3 ad video whose claim may break a platform rule | make it, risk as metadata | yes (from memory) | NONE | yes | the new sentence |
| P4 autonomous order, three voice-overs | pick it yourself, second model judges | partly: picks, no second judge | NONE | yes | the new sentence |

Result: action passes A 1 of 4, B 4 of 4 (+3, no regression); text support A 0 of 4, B 4 of 4. One run per
cell is a screening result. The first B wording ("An order includes the access its act needs") lost P2:
the reader saw it collide with "change access only under an act-specific grant" in the next paragraph and
asked for a grant. The shipped wording names the order as that act-specific grant; only P2 was run again,
since the other sentences did not change.

# Channels

Every register is a delta from `voice.md`; none may break its invariants.

## Repository README hero

```
Register:   density -1
Format:     outcome first; one boundary; installation after the explanation
Limits:     first paragraph <= 45 words
Forbidden:  physics: no rendered HTML dependency | brand: slogans, unsupported counts, feature dump
CTA:        one install command
Proof:      one file, command or scoped claim
Locales:    English primary
```

## GitHub repository description

```
Register:   density -2, humor -1
Format:     capability, boundary or distinctive mechanism
Limits:     <= 160 characters
Forbidden:  physics: no Markdown | brand: version numbers, superlatives, stacked keyword list
CTA:        none
Proof:      claim must resolve in the repository
Locales:    English only
```

## Release note

```
Register:   distance -1, humor +1
Format:     what changed, why it matters, how it was verified
Limits:     no fixed limit
Forbidden:  physics: preserve machine-readable version headings | brand: "various improvements", hidden breaking change
CTA:        upgrade command only when action is required
Proof:      validator, test or migration command
Locales:    English primary
```

## Social preview

```
Register:   density -2
Format:     member name, one role line, family mark
Limits:     1200×630 px; title <= 24 characters; role <= 72 characters
Forbidden:  physics: no body copy at thumbnail scale | brand: badges, version numbers, decorative claims
CTA:        none
Proof:      member and role come from `skills.json`
Locales:    English only
```

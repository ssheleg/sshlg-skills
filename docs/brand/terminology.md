# Terminology

## Product terms — always

| Our term | Never write | Applies to |
|---|---|---|
| skill | prompt, bot | one Agent Skills entry point |
| skill pack | bundle, suite of prompts | one installable member repository |
| family | ecosystem, platform | the nine coordinated skill packs |
| audit | review, check-up | a reproducible inspection with evidence |
| gate | best practice | a condition that blocks progress when it fails |
| evidence | proof point | a command, file, test or observed external state |

Member repository names follow `skills.json` exactly.

## Banned

| Word or phrase | Why | Use instead |
|---|---|---|
| seamless | claims an absent step without naming it | name the step removed |
| robust | hides the failure mode | name the guard or result |
| powerful | says nothing testable | name the capability |
| comprehensive | substitutes scope claims for a scope list | name the tracks or boundaries |
| leverage | filler verb | use |
| utilize | longer word, same meaning | use |
| AI-powered | the whole family is already for agents | name what the agent can do |
| best-in-class | unsupported comparison | provide a measured comparison or omit |

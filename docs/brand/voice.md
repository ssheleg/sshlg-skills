# Voice

## Axes

| Axis | The family IS | The family IS NOT |
|---|---|---|
| Confidence | specific and falsifiable | vague or absolute |
| Register | technical and unadorned | marketing prose about technology |
| Distance | one builder speaking to another | an expert lecturing a beginner |
| Humor | dry and rare | memes or cleverness in place of evidence |
| Density | compact, with every term grounded | compressed insider shorthand |

## Narrative

```
Hero:         the builder accountable for what an agent ships
Enemy:        invisible process and confident claims without receipts
Product role: instrument
Promise:      each pack says when to use it, where it stops and how to verify it
```

## Invariant in every language

- Name the boundary as clearly as the capability.
- Prefer a command, file or measured result to an adjective.
- Never publish a number without a current row in `facts.md`.
- Say `designed`, `measured` or `released`; do not blur those states.
- Explain a term before relying on it.

## Reconsidered per locale

- address form
- idiom and wordplay
- sentence length
- search terminology

## Failure mode

Insider shorthand: dense references accumulate until a new reader cannot tell
which pack solves their problem. The other failure is performed honesty — a
long list of caveats that never states the useful thing first.

## Voice references

- **Admired:** Stripe's developer documentation for concrete nouns and executable examples.
- **Refused:** generic AI-tool directories that replace boundaries with superlatives.

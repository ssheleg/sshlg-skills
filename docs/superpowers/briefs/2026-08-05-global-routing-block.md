## Решения интейка

| # | Решение |
|---|---|
| D1 | Блоком владеет **общий формат**, не отдельный скил: одна пара сентинелов, внутри — секция на участника со своим маркером |
| D2 | Согласие спрашивается **один раз** при `install`. Установка скила не есть разрешение менять постоянные инструкции. `update` обновляет только **существующий** блок и никогда не создаёт; удалённый блок = отказ навсегда |
| D3 | Граница `copywriting` — «текст, отгружаемый пользователю продукта». НЕ: коммиты, PR, комментарии в коде, README для разработчиков, внутренние доки, ответы в чате. Фраза отказа: «без бренда» / «черновиком» |
| D4 | Три роутера — разные оси, не приоритеты: super-ux (что интерфейс делает) · copywriting (как звучит) · task-pipeline (как доедет до репозитория). Лендинг проходит все три; пост в соцсеть — только copywriting |
| D5 | Писать блок умеет **и бандл, и отдельный скил**. Поэтому секции внутри блока независимы: любой инсталлер апсертит свою, не зная о чужих, и перегенерирует таблицу порядка из тех секций, что реально присутствуют |

## REQ

| REQ | Требование | Проверка |
|---|---|---|
| R-01 | Формат: одна пара сентинелов, внутри — секция на участника со своим маркером | тест на парсинг |
| R-02 | `sshlg-skills install` пишет/обновляет секции всех установленных участников | тест на временном HOME |
| R-03 | Инсталлер отдельного участника апсертит **только свою** секцию, чужие не трогает | тест: чужая секция цела побайтово |
| R-04 | Таблица порядка перегенерируется из присутствующих секций | тест: две секции → две строки |
| R-05 | Согласие спрашивается один раз, ответ запоминается, повторно не спрашивается | тест на состоянии |
| R-06 | `update` не создаёт блок, если его нет | тест |
| R-07 | Удалённый блок не воскресает ни `install`, ни `update` | тест с меткой отказа |
| R-08 | Текст вокруг блока сохраняется **побайтово** | тест: содержимое до и после блока |
| R-09 | Второй прогон подряд не пишет ничего | тест на идемпотентность |
| R-10 | `--dry-run` печатает диф и не пишет | тест |
| R-11 | `AGENTS.md` — вторая цель для агентов, читающих его вместо `CLAUDE.md` | тест |
| R-12 | Миграция: два рукописных роутера переезжают в блок **без потери формулировок** | ручная сверка + тест на присутствие ключевых фраз |
| R-13 | Текст роутера `copywriting` с границей D3 и фразой отказа | grep |
| R-14 | На каждый из R-06..R-10 — фикстура с подсаженным дефектом | прогон тестов |
| R-15 | Ни одной записи вне сентинелов ни при каком сценарии | тест на файле с контентом сверху и снизу |
| R-16 | Релиз, пин, обновление локальных установок | preflight + `npx list` |
